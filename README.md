# xhs-video-lab · 小红书视频拆解工作流

一个给 AI 用的 skill：**你只需要把小红书视频链接发给 AI（推荐 [ZCode](https://zcode.ai)），它会自动完成剩下的一切**——

1. 下载视频音频
2. 本地转写逐字稿（faster-whisper large-v3，带时间戳，数据不出你的电脑）
3. 抓取点赞 / 评论 / 收藏 / 分享数据
4. 产出拆解分析：钩子拆解、内容结构时间轴、优劣势、可直接套用的话术
5. 写入你的飞书多维表格（可筛选、排序、统计）
6. 更新一个本地 HTML 工作台（总览统计 / 明细表 / 拆解库 三个页签，双击即开，零依赖）

## 它长什么样

本地工作台包含三个页签：

- **总览**：案例数、累计互动数据、每日新增、领域分布、从全部案例交叉总结出的运营经验
- **明细表**：全字段表格，搜索 + 列筛选 + 排序
- **拆解库**：每个视频的完整拆解 + 三色高亮的逐字稿全文（黄=钩子、绿=金句、蓝=CTA）

## 安装（三步）

前提：一台 Windows/Mac 电脑，会复制粘贴。

1. **装 ZCode 并打开**，把这句话发给 AI：

   ```text
   帮我检查并安装 xhs-video-lab 需要的全部环境：
   Python、yt-dlp、ffmpeg、Node.js、lark-cli（npm 包名 @larksuite/cli）。
   缺什么装什么，每一步先告诉我做什么、需要多久。
   ```

2. **把这个文件夹放进技能目录** `~/.agents/skills/xhs-video-lab`（或让 AI 帮你放）

3. **对 AI 说**：

   ```text
   帮我登录飞书，然后运行 xhs-video-lab 的环境自检
   ```

首次使用时 AI 会问你素材库放哪、帮你写配置；第一次拆视频会下载 AI 模型（约 3GB），只需一次。

## 使用

```text
帮我拆解这条小红书视频：<完整链接>
```

- 链接从电脑浏览器地址栏全选复制（要带 `xsec_token=` 参数）；`xhslink.cn` 短链也可以，会自动解析
- 途中随时可以问 AI：「原理」（这步在干什么）、「步骤」（进度）、「改造」（自定义菜单）
- 处理过的链接重复发不会重复干活

## ⚠️ 隐私提醒（必读）

- **`config.json` 里有你的飞书私人凭证（表格地址、群 ID）。永远不要把它提交到仓库、贴进 issue、或发给任何人。** 它已被 `.gitignore` 排除；首次运行会自动从 `config.example.json` 模板生成
- 你的逐字稿、拆解数据全部存在本地素材库，不经过任何第三方服务器（转写在你电脑上完成）

## 网络说明

- 国内用户：默认直连小红书（无需代理）；仅首次下载 AI 模型需要代理（默认 `http://127.0.0.1:7897`，可在 config 修改）
- 海外用户：在 `config.json` 里把 `"direct_connect"` 设为 `false`，让小红书请求走代理
